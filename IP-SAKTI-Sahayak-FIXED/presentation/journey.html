04 / The demo journey

Question → Route → Classify → Explain.

A founder starts with one practical question. The assistant turns it into a bounded, evidence-aware workflow.

Example question

“Can I commercialize an Ayurvedic herbal formulation using an Indian plant ingredient?”

01

Question

Capture the formulation, intended claim, market, and decision the user is facing.

02

Route

Separate IP, regulatory, ABS, and prior-art signals across India or international scope.

03

Classify

Ask targeted questions to identify the formulation category and missing facts.

04

Explain

Return cited passages, confidence, limitations, and distinct ABS / TKDL pointers.

Human handoff

If the evidence is incomplete or the decision is consequential, package the context and request expert review.

Safe by default
Information · not legal advice
